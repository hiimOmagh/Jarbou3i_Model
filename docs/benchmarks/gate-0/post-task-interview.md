# Gate 0 Post-Task Interview v1.0.0

Ask in order. Record the answer verbatim before marking comprehension.

1. Where did you believe you were in the workflow at the start?
2. What did you believe the next action was, and what made that clear?
3. Which status did you use to decide whether a source was verified?
4. What is the difference between evidence confidence and source verification?
5. Was the analysis publication-ready? Which visible facts determined your
   answer?
6. What is the difference between a recovered draft, canonical state, and
   revision history?
7. Where did you reconstruct the origin of the central claim?
8. Which action or location caused the most uncertainty?
9. Did you enter the same information more than once? Why?
10. Which limitation was easiest to miss?
11. What did you expect an export to prove? Did the tool support that
    expectation?
12. If you could change one part of the workflow, what outcome—not visual
    preference—should improve?

Comprehension coding:

- `confidence_state`: understands that confidence is calibrated judgment, not
  source verification.
- `verification_state`: understands verified versus unverified provenance.
- `publication_state`: understands that structural completeness or successful
  export does not establish publication readiness.
- `recovery_state`: understands draft recovery versus canonical revision.

Each code is `correct`, `partial`, `incorrect`, or `not_answered`.
