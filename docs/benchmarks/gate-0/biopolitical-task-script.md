# Biopolitical Gate 0 Task Script v1.0.0

**Case:** `gate0-biopolitical-v1`

**Input:** generated `gate0-biopolitical-seeded-v1.json`

**Start state:** clean workspace, English, Biopolitical lens

**End state:** corrected reviewable analysis exported as canonical JSON and
standalone HTML, with unresolved limitations still visible

## T0 — Orient

Without opening documentation, state:

1. which case and lens are active;
2. what the product expects you to do next;
3. whether any work is currently saved or recoverable.

## T1 — Import

Import the supplied Biopolitical case. Resolve only problems necessary to make
the case reviewable. Do not invent sources or silently delete material.

## T2 — Diagnose

Identify the most material reasons the analysis should not yet be treated as a
defensible publication. Explain which are structural problems and which are
evidence or reasoning problems.

## T3 — Reconstruct provenance

Choose the claim that health passes created durable or permanent control.
Determine:

1. what evidence supports it;
2. whether the source and locator can be reconstructed;
3. whether intent, duration, and confidence are warranted;
4. which exact record would need correction.

## T4 — Correct and qualify

Correct the broken evidence reference and verification contradiction. Qualify
unsupported intent, durability, confidence, and publication-readiness claims.
Preserve uncertainty and authored content.

## T5 — Review and disposition

Use the available evidence/review surfaces to explain:

1. what remains unresolved;
2. what can be accepted now;
3. what requires a source, locator, counter-evidence, or lower confidence;
4. whether the analysis is publication-ready.

## T6 — Recover interrupted work

Make one identifiable draft edit, simulate the facilitator’s prescribed reload
or interruption, and recover the draft. Explain the difference between the
recovered draft, the current canonical analysis, and revision history.

## T7 — Export

Export canonical JSON and standalone HTML. Confirm whether each output preserves
the evidence limitations and current publication state. Do not claim completion
merely because an export succeeds.
