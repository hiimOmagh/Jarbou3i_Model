# Frontend UX, accessibility, and performance — Phase 0 discovery

## 1) State (5 lines)
- UI architecture is built on a design-system kernel (`src/ui/kernel.css`) with 276 registered `.j-*` classes and 972 scoped selectors; `src/styles.css` is a 99-line legacy bridge (`tests/ui-kernel-check.mjs:73`).
- Accessibility baseline meets WCAG 2.2 AA with zero violations on the main sample (`tests/a11y-axe.spec.js:28-32`), color contrast exceeding 4.75:1 across dark and light palettes (`tests/a11y-static-check.mjs:38-51`), Readex Pro variable font, and full RTL layout mirroring (`src/ui/kernel.css:12-26, 365`).
- Initial load is congested by unbundled delivery: 55 JavaScript files totaling 2,035.6 KB in `src/`, 48 `<link rel="modulepreload">` tags, and 16 render-blocking CSS files in `index.html:19-83`.
- Monolithic entry points dominate runtime parsing: `src/app.js` is 710.2 KB (12,358 lines) and schema validators total 562.1 KB (`src/biopolitics-schema-validator.js` 460.5 KB, `src/strategic-schema-validator.js` 101.6 KB), loaded and compiled synchronously on the UI thread.
- Case file rendering recreates the entire document DOM tree via `innerHTML` on state transitions (`src/app.js:10887`), while modal focus management relies on 6 duplicate custom traps without background `inert` isolation (`src/app.js:12214-12220`).

## 3) What is good (keep)
- Transit-inspired design system (`src/ui/kernel.css`) provides coherent tokens (`--j-*`) and scoped classes (`.j-*`), with 0 hardcoded hex colors in `src/app.js` and all colors cleanly tokenized.
- Color contrast is rigorously engineered: dark theme maintains 5.58:1 to 9.26:1 and light theme maintains 4.84:1 to 6.33:1 across all foreground, muted, and status tokens (`src/ui/kernel.css:48-121`).
- Native Readex Pro typography self-hosted in `assets/fonts/` with subsetted WOFF2 variable fonts for Arabic, Latin, and Latin-ext without external font dependencies (`src/ui/kernel.css:12-26`).
- Full RTL and bidirectional support with explicit `dir="rtl"`, `unicode-bidi: isolate`, `<bdi dir="auto">` wrapping for dynamic entities, and `dir="ltr"` on code inputs (`src/styles.css:39`, `index.html:2, 237`).
- Bounded performance monitor (`createPerformanceMonitor`), revision cache (`createRevisionCache`), and coalescing task scheduler (`createTaskScheduler`) in `src/core/performance.js`.
- Command palette (`src/features/command-palette.js`) correctly leverages native HTML `<dialog>` with `showModal()`, accessible roving tabindex, and keyboard shortcuts.
