# Documentation — Phase 0 discovery

## 1) State (5 lines)
- Extensive documentation exists across architecture, contracts, operations, features, and ADRs, but feature indexing is fragmented: 5 of 7 specifications in `docs/features/` are completely omitted from the main documentation hub. Evidence: `docs/README.md:9-12`; `docs/features/`.
- All six Architecture Decision Records remain marked as "Proposed" despite being fully implemented and running in production, while major subsequent architectural work (RESEARCH-1D file reading, Git flow, release delegation) lacks ADRs entirely. Evidence: `docs/decisions/README.md:8-13`; `docs/decisions/*.md:3`; `docs/features/research-attachments.md:1-15`.
- Core governance and contribution documentation contains internal contradictions regarding the primary branching workflow, with `CONTRIBUTING.md` instructing branching from `main` in one section and from `ux0-preview` in another, and `deployment.md` claiming strict status checks while `release-process.md` verifies `strict: false`. Evidence: `CONTRIBUTING.md:27-41,68-72`; `docs/operations/deployment.md:30`; `docs/operations/release-process.md:22`.
- Obsolete Gate 0 human benchmark prerequisites persist across multiple authority documents and are enforced by automated test assertions, despite Gate 0 having been formally waived in ADR-0002. Evidence: `docs/decisions/0002-select-case-file-and-waive-gate0.md:26`; `docs/benchmarks/gate-0/README.md:5`; `docs/product-ui-execution-plan.md:20`; `tests/version-authority-check.mjs:46`.
- User-facing onboarding and operational guides omit major shipped capabilities, most notably the entire Case File / Research Dossier workflow and local file passage reading, leaving no mention of dossiers in `README.md` and outdated prompt-only instructions in `docs/usage-guide.md`. Evidence: `README.md:18-58`; `docs/usage-guide.md:19`.

- Core analytical contract documents (`docs/ai-interchange-contract-v1.md`, `docs/biopolitical-v2-contract.md`, `docs/export-contract.md`) provide unambiguous normative standards with exact schema mappings and validation matrices.
- Trilingual terminology guidance, language parity rules, and epistemic caution are documented consistently in `docs/usage-guide.md` and `docs/biopolitical-v2-contract.md`.
- Release history and change provenance in `CHANGELOG.md` are maintained with rigorous detail across all 57 alpha releases.
